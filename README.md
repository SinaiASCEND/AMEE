# ASCEND at AMEE 2026

Companion site for the Office of Curricular Affairs' three short communications at
AMEE 2026 (Vienna, 24 August 2026).
Published at https://sinaiascend.github.io/AMEE/

## Contents

    index.html        Overview of the three presentations
    shadowing.html    Pre-clerkship shadowing program (Session 4I, Chadha / Strother / Soriano)
    corecluster.html  Core + Cluster physical examination framework (Session 4J, Soriano et al.)
    framework.html    Core + Cluster: the full specification, 24 core maneuvers, 8 clusters
    grading.html      Criterion-referenced clerkship grading (Session 4H, Holzer / Fallar / Soriano)
    contact.html      Contact
    files/            Downloadable PDFs, linked from corecluster.html

Every page carries the same five-item navigation (top bar on desktop, bottom tab bar on
phones). Adding a page means adding it to the navigation on all six pages.

## Updating a PDF

Replace the file in `files/` keeping the same name. No HTML changes needed.

    files/CoreCluster_Soriano_AMEE2026_slides.pdf     the Core + Cluster slides
    files/CoreCluster_24_maneuvers.pdf                the core, by section
    files/CoreCluster_crosswalk.pdf                   Gowda / Jewett / ISMMS
    files/CoreCluster_Soriano_AMEE2026_abstract.pdf   the abstract

Slides for the shadowing and grading presentations are not yet posted; add them under
`files/` and link them from a "Materials" section on that presentation's page.

The Icahn logo, ASCEND tagline and QR code stay embedded in the HTML.
