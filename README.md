# Core + Cluster — AMEE Vienna 2026

Companion site for the short communication at AMEE 2026 (Session 4J, 24 August).
Published at https://sinaiascend.github.io/AMEE/

## Contents

    index.html        Overview, materials, abstract, references, contact
    framework.html    The full specification: 24 core maneuvers, 8 clusters, all criteria
    files/            Downloadable PDFs, linked from index.html

## Updating a PDF

Replace the file in `files/` keeping the same name. No HTML changes needed.

    files/CoreCluster_Soriano_AMEE2026_slides.pdf     the presentation slides
    files/CoreCluster_24_maneuvers.pdf                the core, by section
    files/CoreCluster_crosswalk.pdf                   Gowda / Jewett / ISMMS
    files/CoreCluster_Soriano_AMEE2026_abstract.pdf   the abstract

The Icahn logo, ASCEND tagline and QR code stay embedded in the HTML — they are
small, used on both pages, and change rarely.
